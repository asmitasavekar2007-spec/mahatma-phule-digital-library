
# Mahatma Phule Library
### Digital Library Management System

A bilingual (Marathi and English) digital library website being developed for **Sadashivrao Mandlik Mahavidyalaya, Murgud**.

## Project Overview

The Mahatma Phule Library website aims to provide students, teachers and researchers with convenient online access to library information, academic resources, previous-year question papers and digital learning materials.

The project also aims to provide an administrative dashboard through which authorized library staff can manage website content and resources.

## Objectives

- Digitize library information and resources.
- Provide easy access to previous-year question papers.
- Support Marathi and English languages.
- Simplify library content management.
- Promote digital learning and research.

## Planned Features

- Responsive homepage
- About the library
- Library staff and facilities
- Library rules and regulations
- Book search (OPAC)
- Previous-year question papers
- Digital library and study materials
- E-resources and research resources
- New arrivals
- Notices and announcements
- Photo gallery
- Contact information
- Administrative dashboard

## Planned Admin Panel

- Secure administrator login
- Librarian and assistant roles
- Content management
- Course and subject management
- Question paper PDF management
- Notice management
- Photo gallery management
- Marathi and English content management
- Website settings
